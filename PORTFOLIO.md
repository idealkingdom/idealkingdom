# Jeff Eric Cabarrubias — portfolio

Static, dependency-free HTML/CSS/JavaScript in `docs/`. Designed for GitHub Pages using the `main` branch and `/docs` folder. The existing profile README stays separate.

## Content

- Resume and supplied career details are the content sources.
- Keiken, migration automation, and KX are described as professional work; their illustrations are conceptual.
- AuthScaffold and WinSuture link to their public source repositories.
- Light is the default; the explicit theme choice persists locally.
- Resume download, email, LinkedIn, and GitHub links are included.
- No analytics, trackers, remote UI assets, forms, or API keys.

## Maintenance

Edit `docs/index.html` for content, `docs/styles.css` for design, and `docs/script.js` for the theme behavior. Replace `docs/assets/Jeff_Eric_Cabarrubias_Resume.pdf` when the resume changes. Do not include employer source code or internal screenshots.

Serve `docs/` with any static HTTP server for local development. No build step is required. All internal asset paths are relative, so the site works under the GitHub Pages project path.
